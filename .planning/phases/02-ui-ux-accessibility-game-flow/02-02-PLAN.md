Solver.ts — add static findHintPair(stones: Stone[]): [string, string] | null method:
1. Filter stones to free only: stones.filter(s => !s.picked && isFree(s)) — note: isFree is on BoardModel, but the solver needs a standalone version. Use the same logic: !s.picked && s.top.every(t => t.picked) && !(s.left.length > 0 && !s.left.every(l => l.picked) && s.right.length > 0 && !s.right.every(r => r.picked)). Import the isBlocked function if it exists as a standalone export from the engine.
2. Use O(n^2) scan: for each free stone i, check all later free stones j — if free[i].face === free[j].face, return [free[i].id, free[j].id].
3. Return null if no matching pair found (deadlock).
4. This is a simple scan, not exhaustive — it finds the FIRST matching pair by scan order. Per D-06, the user still clicks the highlighted tiles; any valid pair is correct.

BoardModel.ts — add shuffle(): void method:
1. Get all remaining (non-picked) stones via this.getRemaining().
2. Extract their current {x, y, z} positions into an array.
3. Fisher-Yates shuffle the positions array in place.
4. Reassign shuffled positions back to the remaining stones: stone.x = positions[i].x, stone.y = positions[i].y, stone.z = positions[i].z.
5. Call buildNeighbors(this.stones) to rebuild neighbor topology after position reassignment.
6. Note: per RESEARCH.md assumption A4, shuffled layouts may become unsolvable — this is acceptable. Deadlock detection will catch it. Use Math.random() for the shuffle (the game is deterministic only for level generation).

GameState.ts — add undo/hint/shuffle with usage limits:
1. Add private fields:
   - actionHistory: Array<{ stoneIds: [string, string]; face: number; trayIndices: [number, number] }> (max depth 3 per D-05)
   - undoCount: number = 3
   - hintCount: number = 3
   - shuffleCount: number = 1
2. Add public isTerminal(): boolean — returns the existing private terminal field. If terminal is already public or accessible, skip.
3. Modify tapStone(): after a successful match (result.matched === true), push an undo entry to actionHistory before removing from tray: { stoneIds: [stone1.id, stone2.id], face: stone1.face, trayIndices: [index1, index2] }. If actionHistory.length > 3, shift the oldest entry (FIFO).
4. Add public undo(): boolean:
   - If undoCount === 0 or actionHistory.length === 0, return false.
   - Pop the last entry from actionHistory.
   - For each stoneId in entry.stoneIds: set stone.picked = false, add back to board.remaining, remove from tray.
   - Call board.buildNeighbors(board.getStones()) to rebuild neighbor topology.
   - undoCount--; return true.
5. Add public hint(): { stoneId: string; partnerId: string } | null:
   - If hintCount === 0, return null.
   - Call Solver.findHintPair(board.getStones()).
   - If result is null (deadlocked), do NOT decrement hintCount — return null.
   - If result is non-null, hintCount--; return { stoneId: result[0], partnerId: result[1] }.
6. Add public shuffle(): boolean:
   - If shuffleCount === 0, return false.
   - Call board.shuffle().
   - shuffleCount--; return true.
7. Add public getters: getUndoCount(), getHintCount(), getShuffleCount().
8. In reset(): reset undoCount=3, hintCount=3, shuffleCount=1, actionHistory=[].

config.ts — add assist button limits:
