Create new file src/audio/AudioManager.ts — singleton audio manager using native Web Audio API (D-12, D-13):

Core structure:
- Export class AudioManager with private static instance: AudioManager.
- static getInstance(): AudioManager — returns instance or creates new one.
- Private fields: ctx: AudioContext | null, sfxGain: GainNode | null, bgmGain: GainNode | null, sfxMuted: boolean (false), bgmMuted: boolean (false), sfxVolume: number (0.7), bgmVolume: number (0.4), initialized: boolean (false).

init(): Promise<void> — called from first user gesture (home button tap):
1. this.ctx = new AudioContext().
2. Create bus nodes: this.sfxGain = this.ctx.createGain(); this.sfxGain.gain.value = this.sfxVolume; this.sfxGain.connect(this.ctx.destination).
3. this.bgmGain = this.ctx.createGain(); this.bgmGain.gain.value = this.bgmVolume; this.bgmGain.connect(this.ctx.destination).
4. this.initialized = true.
5. If ctx.state === 'suspended', call ctx.resume().
6. Return Promise that resolves when ctx.state === 'running' (or after resume).

playSfx(type: 'tap' | 'match' | 'combo' | 'win' | 'fail' | 'click'): void (D-15):
- If !this.ctx || !this.sfxGain || this.sfxMuted, return.
- If ctx.state !== 'running', try ctx.resume() then return (don't play if still suspended).
- Create OscillatorNode + GainNode per type:
  - tap: type='sine', frequency=880, duration=0.15s, gain 0.3→0.001 exponential ramp
  - match: type='triangle', frequency=660, duration=0.20s, sustain 0.3 for 100ms then decay
  - combo: type='square', frequency=1047, duration=0.25s (filter harshness with a BiquadFilterNode lowpass at 2000Hz if available)
  - win: type='sine', 3 oscillators at 523/659/784Hz (C-E-G chord), duration=0.6s, staggered start (0ms, 80ms, 160ms)
  - fail: type='sine', frequency ramp from 440→330Hz over 0.4s, gain decay
  - click: type='sine', frequency=1047, duration=0.08s, very short attack 3ms
- Connect each osc → gain → this.sfxGain.
- Call osc.start(ctx.currentTime + delay) and osc.stop(ctx.currentTime + delay + duration).
- Each SFX function should be standalone (no state shared between calls). Oscillators auto-disconnect after stop.

startBgm(): void — pentatonic melody loop:
- If !this.ctx || !this.bgmGain || this.bgmMuted, return.
- Use a private bgmPlaying: boolean flag to prevent duplicate loops.
- Define a melody array of { frequency: number; duration: number } using Chinese pentatonic scale: C=262, D=294, E=330, G=392, A=440 (and octave doubles at 524, 588, 660, 784, 880).
- Create a 16-bar pattern (~80 BPM = 750ms per beat): schedule each note via oscillator with type='triangle'. For each note, also add a soft overtone at 2x frequency with type='sine' and gain 0.15.
- Use ctx.currentTime-based look-ahead scheduling: schedule 4 bars ahead, set a timer (setInterval) to reschedule next block when within 2 bars of the end. This creates a seamless loop.
- Store scheduled oscillator references in a private array for cancellation on stopBgm().
- Set bgmPlaying = true.

stopBgm(): void:
- Disconnect all active BGM oscillators from bgmGain.
- Clear the scheduling timer (clearInterval).
- bgmPlaying = false.

Volume/mute controls:
- setSfxVolume(v: number): clamp 0-1, set this.sfxGain.gain.value = v, store this.sfxVolume = v.
- setBgmVolume(v: number): same for bgmGain, store this.bgmVolume = v.
- setSfxMuted(m: boolean): if m, store current volume then set gain to 0. If unmuting, restore stored volume. Set this.sfxMuted = m.
- setBgmMuted(m: boolean): same logic for BGM. If muting while playing, don't stop the loop — just set gain to 0. Unmuting restores volume.
- getSfxVolume(): number, getBgmVolume(): number, isSfxMuted(): boolean, isBgmMuted(): boolean.
