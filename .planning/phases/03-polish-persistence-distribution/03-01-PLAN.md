## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage (browser) → App | Data read from localStorage is inherently untrusted — any user can modify it via DevTools. This is acceptable for a single-player offline game. |
| Service Worker → App (covered in Plan 03-02) | Not in scope of this plan. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | localStorage (currentLevel, audio settings) | low | accept | Users can modify localStorage via DevTools; this is a single-player offline game with no competitive/economic impact. Parse defensively: parseInt fallback to 1, JSON.parse fallback to defaults. |
| T-03-02 | Denial of Service | localStorage quota | low | mitigate | localStorage.setItem can throw QuotaExceededError. Mitigation: persist callers are called infrequently (WIN event, settings onChange) — well under the ~5MB limit. If quota is exceeded, the game continues in-memory; no data loss toast needed per UI-SPEC. |
| T-03-SC | Tampering | npm install vite-plugin-pwa | high | mitigate | slopcheck audit in RESEARCH.md Package Legitimacy Audit: vite-plugin-pwa v1.3.0 is OK (4+ yrs, 3.3M/wk, verified npm registry + GitHub). No [ASSUMED]/[SUS] packages. |
