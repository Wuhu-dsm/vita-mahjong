## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build script → generated PNG/CSS/JSON | Generated static assets cross from build-time Node context to runtime load context. |
| CDN font CSS → renderer | External font stylesheet is loaded by the browser. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Tampering | npm/pip package installs | high | mitigate | No new packages are added; reuse `tsx` from Plan 01-01 which passed the 01-RESEARCH.md legitimacy audit. |
| T-01-SC | Tampering | npm/pip package legitimacy checkpoint | high | mitigate | If any asset-generation dependency is introduced, verify it against the audit or pause for human approval. Current plan adds no new packages. |
| T-01-06 | Tampering | Generated PNG/JSON files | low | mitigate | Generated files are deterministic from committed scripts; they are gitignored and regenerated on every build. Runtime does not execute these files as code. |
| T-01-07 | Information Disclosure | CDN font request | low | accept | Loading a public Google Fonts CSS reveals only the user agent/IP to the CDN; no user data is transmitted. Accept for Phase 1. |
</threat_model>
