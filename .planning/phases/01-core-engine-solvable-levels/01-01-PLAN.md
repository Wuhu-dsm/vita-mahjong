    - BoardModel reports edge tiles as free when not covered from above.

  <action>
    Create `src/engine/types.ts` exporting `Stone` (id, z, x, y, face, picked), `Level` (id, name, stones, theme, maxLayer), and helper types. Create `src/engine/isBlocked.ts` exporting a single shared helper `isBlocked(stone: Stone, stones: Stone[]): boolean` and `hasUnpicked(stones: Stone[]): boolean`. The helper computes neighbor references from the stones array per the PRD free-tile rule: `top` = stones at z+1 whose footprint overlaps (tile footprint spans x to x+1 and y to y+1; overlap when x ranges intersect and y ranges intersect); `left` = same-z stone whose right edge touches this stone's left edge (x+2 neighbor on the grid); `right` = same-z stone whose left edge touches this stone's right edge. It returns `hasUnpicked(top) || (hasUnpicked(left) && hasUnpicked(right))`. Create `src/engine/BoardModel.ts` as a pure TypeScript class. It accepts a `Level`, builds an internal list of `Stone` objects, and delegates `isBlocked(stone)` to the shared helper. Implement `isFree(stone)` as `!isBlocked(stone) && !stone.picked`. Implement `pick(stone)` to mark a stone as picked/removed and return the updated board. Implement `getRemaining()`, `getFree()`, and `hasWon()` (remaining === 0). Implement `isDeadlocked()` returning true when no free stones remain and the board is not won. Create `src/engine/Solver.ts` exporting a `Solver` class with a static `isSolvable(level: Level)` method. The solver simulates the tray mechanic: repeatedly choose any free stone, add it to a virtual 4-slot tray, remove pairs immediately, and fail if the tray ever holds 4 unmatched stones. Use a deterministic choice order so the function is testable. Create `src/__tests__/BoardModel.test.ts` and `src/__tests__/free-tile.test.ts` using Vitest. Include tests for: a single uncovered stone is free; a stone with a top neighbor is blocked; a tile with both left and right neighbors blocked is blocked; a tile with only a left neighbor is free; picked stones are not returned by getFree. Avoid importing PixiJS in engine files. The shared helper ensures the free-tile rule used at runtime matches the rule used during build-time generation (per D-07/D-08).
  </action>

If a matching face already exists anywhere in the tray, clear that slot and return the partner and the new stone in `removed`.
