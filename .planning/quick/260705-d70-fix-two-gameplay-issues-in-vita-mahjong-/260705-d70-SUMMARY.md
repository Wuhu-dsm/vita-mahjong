# Quick Task 260705-d70: Fix rapid-tap drops and rectangular layouts

**Completed:** 2026-07-05

## Changes Made

1. **Queued rapid taps in `src/renderer/screens/GameScreen.ts`**
   - Added a `tapQueue: string[]` to store stone ids tapped while an animation is running.
   - `handleTileTap` now enqueues the id instead of silently dropping it when `inputLocked` is true.
   - `processTapQueue()` drains one queued tap after each animation sequence finishes, so rapid consecutive taps execute sequentially instead of being lost.
   - The queue is cleared when a new level is loaded.

2. **Made level layouts less regular in `src/generator/LayoutBuilder.ts`**
   - Added deterministic row-width variation to `layerPositions` via `distributeRowWidths`.
   - When a layer would be a perfect rectangle, an extra row is added so the shape gains jagged edges while keeping the same tile count.
   - Width reductions are distributed deterministically per level/layer using a seeded hash, keeping layouts reproducible.
